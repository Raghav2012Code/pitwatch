# PitWatch identity

The mark joins the nested benches of an open pit with an observing eye. The central diamond is a survey point, not a severity indicator. The website pairs it with its existing Archivo wordmark.

- `public/logo.svg`: transparent slate mark, redrawn as paths for sharp scaling.
- `public/favicon.svg`: bolder two-ring version of the mark on a slate tile, with an ochre survey point, drawn to stay legible at 16 px.
- `public/favicon-32.png`: 32 px browser fallback.
- `public/apple-touch-icon.png`: 180 px home-screen icon with an opaque slate background.
- `generated-mark.png`: original transparent image from the built-in image generation tool; visual reference for the production SVG.

The header mark inherits the ink token. Standalone assets use the same ink (`#23262b`) and panel (`#f8f7f3`) values. Keep the internal negative spaces clear; do not stretch the mark.

## Generation prompt

Use case: logo-brand. Create one final professional modern logomark for PitWatch 3D, a topographic open-pit mine monitoring website. Symbol only, absolutely no text or letters, no presentation board or mockup. A strong geometric eye made of three nested angular terraced open-pit contour loops, a small solid diamond survey point at its centre. Horizontally oriented eye silhouette but fitting comfortably within a square. Precise engineered geometry, distinctive and restrained Swiss industrial identity, thick even strokes and generous negative spaces, only three nested shapes so recognizable at 16 pixels. Flat single solid slate ink #23262b, all negative spaces genuinely transparent. No gradients, shading, shadows, textures, 3D effects, fine lines, ornamental ticks, mountains, shields, pickaxes, circles outside the eye, or stock clipart. Centred mark with 10 percent padding, transparent background. This must be an exceptionally clean vector-like logo suitable for a technical surveying product. Palette matches limestone survey paper site with slate ink typography.
